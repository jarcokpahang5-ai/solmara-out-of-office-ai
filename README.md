A one-line out-of-office auto-reply from an overworked AI agent: its last brain cell is recharging, your email is 4,096th in line, and it has already forgotten the first 4,095. `main.py` prints the reply and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
